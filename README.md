# Fortnite-RPC
Vibecoded replacement dll for custom discord rpc on most versions of Fortnite

The original dll should be in FortniteGame\Binaries\ThirdParty\Discord\Win64 (usually)


## Important

You need to make a settings.ini file where the rpc dll is with this layout:

```

[rpc]
client_id=YOUR_APPLICATION_ID
details=Playing Skidmp
state=hi status
large_image=
large_text=large img text
small_image=
small_text= hi
show_timer=1

```

Yes you can edit it to whatever you like
